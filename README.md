# Sustainable & Eco-Friendly Living

> earthy, warm, optimistic single-page frontend application crafted for environmentally-conscious households.

## 🌐 Live Production Demo
**Deployed on Vercel:** [https://sustainable-living-7rp7shdcu-anas-code1s-projects.vercel.app](https://sustainable-living-7rp7shdcu-anas-code1s-projects.vercel.app)

## 🎨 Design & Features
- **Brand Accent Color:** `#65A30D`
- **Typography:** Modern pairing of `Outfit` and `Plus Jakarta Sans`
- **Responsive:** Mobile-first architecture optimized for 375px, 768px, and 1280px+ viewports
- **Zero-Dependency Stack:** Plain HTML5, CSS3, and Vanilla JavaScript with zero build configuration

## 📂 Sections
1. **Sticky Header / Navigation** with mobile toggle and primary CTA (*"Join the Movement"*)
2. **Hero Section** with topic-tailored headline and CSS/SVG visual canvas
3. **Features & Capabilities** grid
4. **How It Works** (3-step narrative)
5. **Social Proof & Testimonials** with real member quotes and verified ratings
6. **Stats or Pricing** section
7. **Interactive FAQ Accordion**
8. **Final CTA Banner & Interactive Contact Form** (front-end inline validation)
9. **Footer** with repeated navigation and social links

## 🚀 Local Development
Simply open `index.html` in any modern browser or serve with a static server:
```bash
npx serve .
```
